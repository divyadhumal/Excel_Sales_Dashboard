# Excel_Sales_Dashboard

 

### 🚀 Why I Built This 

I wanted to understand how data analysts turn raw sales data into meaningful insights and present it in a way that helps decision-makers. So I took a dataset and started shaping it into something useful.

This dashboard became my way of learning:

- How sales vary by product category
- How profit changes over multiple years
- Which states perform better
- Which customers contribute the most
- How monthly sales rise and fall

It was a simple idea… but it taught me a lot.

### 🎨 What I Designed

Instead of making a basic Excel file, I focused on creating a clean, modern, and interactive dashboard:

- A funnel chart to show category-wise sales
- A line chart to visualize profit growth
- A map chart to explore state-wise performance
- A customer count panel for yearly comparison
- A pie chart for top 5 profitable customers
- A monthly sales trend chart
And interactive slicers to filter by Year and Category

Everything updates automatically — making it feel like a real analyst dashboard.

### 🧠 What I Learned

This project strengthened my understanding of:

- Data cleaning
- PivotTables & PivotCharts
- Power Query basics
- Designing dashboards with purpose
- Creating a theme and maintaining consistency
- Presenting insights the way companies expect

Most importantly, it helped me build the confidence to create data stories — not just charts.

### 💼 Why This Project Matters (For Recruiters)

This dashboard shows that I can:

- Understand data from a business perspective
- Build a structured, interactive Excel dashboard
- Communicate insights clearly
- Pay attention to design and presentation
- Learn independently and complete end-to-end projects

It’s not just an Excel sheet — it’s the story of how I learned to think like a data analyst.
